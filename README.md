# ✨ Online Sudoku Solver (High-Fidelity)

A premium, interactive web application that visually demonstrates the **Backtracking Algorithm** in action. Designed with a sleek, modern glassmorphism UI, this tool serves as both a powerful Sudoku solver and an educational tutorial.

## 🚀 Features

- **Real-Time Visualization:** Watch the backtracking algorithm evaluate, guess, and re-evaluate numbers on the board in real-time.
- **Dynamic Speed Control:** Adjust the visualization speed on the fly—from instant solving to slow, step-by-step educational pacing.
- **Premium UI/UX:** Built with a "dark mode" glassmorphism aesthetic, featuring neon accents and micro-animations for an elevated user experience.
- **Smooth Scroll Animations:** Elements elegantly reveal themselves with smooth staggered fade-in animations as you scroll down the page.
- **Integrated Tutorial:** Includes an intuitive side-panel explaining the logic and steps of the Backtracking Algorithm.
- **Puzzle Generator:** Instantly generate randomized, valid Sudoku puzzles of varying difficulties.

## 🛠️ Tech Stack

- **Frontend:** React.js, Vanilla CSS (CSS Modules & Variables)
- **Algorithms:** Asynchronous Depth-First Search (Backtracking)
- **Deployment:** Vercel

## 📦 Local Installation

To run this project locally, make sure you have Node.js installed.

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/onlinesuduko.git

# Navigate into the directory
cd onlinesuduko

# Install dependencies
npm install

# Start the development server
npm start
```
The app will open automatically at `http://localhost:3000`.

## 🌐 Deployment to Vercel

This repository includes a `vercel.json` configuration file, making it instantly deployable.
1. Connect this repository to your Vercel account.
2. Ensure the Framework Preset is set to **Create React App**.
3. Deploy! The routing is automatically handled.
